6AI-ready website

Make each brand easy for AI answer engines (ChatGPT, Claude, Perplexity, Google AI Overviews) to read, quote and recommend, and keep paid content private. Only what is built into the template; per-brand content comes later. All native Wix settings, no custom code.

Decision from the site owner before starting
  • Allow or block AI training crawlers, for all brands (task 2)

1. Structured data (JSON-LD) slots

Markup is set up once with placeholders, so each brand only fills in its own values. Wix accepts JSON-LD only, max 8,000 characters per page.

Where in Wix: Static page: page SEO settings → Advanced → Structured Data Markup. CMS and app pages: Dashboard → SEO Settings → Edit by page type.

Starter for the Home page (filled per brand):

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "[Brand name]",
  "url": "https://[domain]",
  "logo": "https://[domain]/logo.png",
  "description": "[One-sentence description of what the brand does]",
  "sameAs": ["https://www.linkedin.com/company/[page]"]
}
</script>

2. AI crawler policy (robots.txt)

Search and AI answer bots stay allowed; training bots follow the owner’s one decision for all brands.

Where in Wix: Dashboard → SEO → Tools and settings → Robots.txt Editor. Keep Wix’s default lines.

If the owner blocks training bots, add:

User-agent: GPTBot
Disallow: /

User-agent: ClaudeBot
Disallow: /

User-agent: Google-Extended
Disallow: /

User-agent: CCBot
Disallow: /

3. Protect paid and gated content

Paid content can’t be read by any crawler or AI tool; public pages stay fully readable.

Where in Wix: Pages panel → permissions; CMS collection permissions; page SEO settings.

4. Answer-shaped page templates

Saved sections let the owner write content AI tools can quote, without developer help.

Where in Wix: Saved sections or CMS-driven blocks in the master template.

5. Authority building blocks

The places where each brand’s credentials will show, built once (content added per brand).

Where in Wix: Article page, About page.

6. Email capture setup

Two signup forms with separate automations: Newsletter in the footer, Free guide everywhere a lead magnet is offered.

Where in Wix: Wix Forms, Wix Automations.

7. Machine-readable offers and checkout

Prices and buying steps are clear to people and AI shopping tools.

Where in Wix: Product page settings, Stores checkout settings.
