Per-brand launch approach

Owner’s reference for launching a brand from the finished template. Not part of the developer’s scope.

Per-brand launch approach

  1. Hide, don't delete. When a brand is ready to launch with just a landing page, nothing else gets removed from the site — every other page stays fully built, ready to switch on later with no rebuild.
  2. Set the landing page as the homepage, remove it from the main menu, and switch its layout to "No Header & Footer" so it has no navigation linking anywhere else.
  3. Don't link out from the landing page to any other page — no buttons, no footer links.
  4. Set every other page to noindex in its SEO settings, so it isn't crawled or found by search while hidden.
  5. Known limit: this hides pages from discovery, not from direct access — anyone with the exact URL could still open them. For anything that genuinely needs to stay locked, restrict it to Members Area or a page password instead of relying on hiding alone.
  6. To reveal later: add the page back to the menu and clear its noindex setting — no rebuild required.
